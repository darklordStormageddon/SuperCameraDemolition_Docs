### 1. 게임 개요

**장르:** 물리 상호작용 기반 코미디 / 퍼즐 / 샌드박스

**핵심 콘셉트:**
시한폭탄이 째깍거리는 화보 스튜디오에서, 제한 시간 안에 세트를 꾸미고 모델의 아크로바틱한 순간을 완벽한 한 장으로 담는 게임. 셔터가 찰칵하는 순간 폭탄이 터지고, 스튜디오가 난장판이 되는 모습을 여러 각도의 슬로모션으로 지켜본다. 그리고 결과창에는 아무 일도 없었다는 듯 완벽한 화보 한 장이 남는다.

플레이어는 화보 스튜디오의 포토그래퍼다. 스테이지마다 아트 디렉터(AD)는 특정한 화보 콘셉트(웨스턴 점프 샷, 무중력 SF 화보, 꽃잎 웨딩 화보 등)를 주문한다. 스테이지가 시작되면 시한폭탄의 카운트다운이 흐르기 시작한다. 플레이어는 그 시간 안에 소품과 조명을 배치하고, 모델의 위치와 포즈를 정하고, 폭탄을 놓고, 삼각대에 고정된 카메라로 구도를 잡는다.

카운트다운이 0이 되면 폭탄에 연결된 셔터가 끊기고, **그 순간이 사진이 된다.** 모델은 공중에서 완벽한 포즈를 취하고 있다. 그리고 바로 다음 순간 폭탄이 터진다. 시간은 **0.2배속**으로 느려지고, 화면은 스튜디오 곳곳의 카메라 시점을 오가며 소품이 연쇄로 부서지고 모델이 포즈 그대로 날아가는 모습을 보여준다.

**핵심 재미**
- 째깍이는 카운트다운 속에서 세트·소품·포즈·폭탄 위치를 짜는 긴장감
- 고정된 카메라 앞에 모델의 가장 멋진 순간을 정확히 담아내는 사진의 재미
- 폭탄이 만든 연쇄 난장판을 여러 각도 슬로모션으로 감상하는 쾌감
- 완벽한 화보와 폐허가 된 스튜디오의 대비가 만드는 코미디

### 2. 세계관 및 설정

패션 잡지 「BOOM」의 화보는 업계에서 전설이다. 표지 모델들의 포즈는 하나같이 믿을 수 없을 만큼 역동적이고, 표정은 살아 있다.

비밀은 촬영 방식에 있다. 「BOOM」의 스튜디오에서는 카메라 셔터가 **시한폭탄의 타이머**에 연결되어 있다. 카운트다운이 0이 되는 순간 셔터가 끊기고, 그 직후 폭탄이 터진다. 편집장은 이렇게 말한다.

"폭발 직전의 1초가 사람을 가장 아름답게 만들지."

모델은 전직 서커스 곡예사 출신의 베테랑으로, 폭탄이 터지는 스튜디오에서도 프로 근성으로 포즈를 끝까지 지킨다. 스튜디오는 매번 박살 나지만, 다음 호 표지는 언제나 완벽하다.

폭발은 만화적인 연출로만 다룬다. 모델은 날아가고 그을음을 뒤집어써도 다치지 않으며, 다음 촬영에 멀쩡히 돌아온다.

### 3. 핵심 게임 시스템

게임은 세 가지 단계로 구성된다.

```
SETUP (제한 시간 · 세팅 · 총으로 폭탄 → 실시간 연쇄 · 셔터) → ACTION (약 10초: 줌인 불릿캠 → 모델 주위 카메라 3대) → REVIEW (화보 공개) → 재촬영 또는 다음 촬영
```

#### PHASE 01. SETUP — 세팅, 폭탄, 셔터

스테이지가 시작되면 제한 시간(기본 90초)이 흐른다. 실제 시간으로 흐르고 Tab 메뉴를 여는 동안만 멈춘다. 남은 시간은 전광판을 들고 플레이어 주위를 뛰어다니는 **타임키퍼**가 보여준다(항상 플레이어를 바라봄).

플레이어는 포토그래퍼의 1인칭 시점으로 스튜디오를 돌아다니며 세팅한다.
- 소품·장비·폭탄·모델 이동과 배치, 모델에게 말을 걸어 **포즈 카드** 선택
- 조준선이 상호작용 대상(들 수 있는 소품, 모델, 폭탄)을 가리키면 대상이 빛나고 **위에 이름표(ID)** 가 뜬다
- 고정 카메라를 들여다보고 구도 결정(방향·줌). 뷰파인더에는 3:2 창, 3분할 격자, 포즈 정점 고스트, 폭탄 노출 경고

**폭탄 → 실시간 연쇄 → 셔터**
1. 준비가 되면 **들고 있는 총으로 폭탄을 쏜다**(우클릭으로 조준 줌인). 첫 발을 쏘는 순간부터 세상이 **슬로모션**이 되어 총알이 날아가는 것이 보인다. 맞으면 폭탄이 터지고, 폭풍과 연쇄 사고가 슬로모션으로 펼쳐진다. 포토그래퍼는 정상 속도로 움직여 카메라까지 달려갈 수 있다.
2. 폭탄이 터지는 순간 모델이 선택한 포즈 카드를 시작한다(폭풍에 맞으면 포즈 대신 날아간다).
3. 플레이어는 카메라로 달려가 들여다보고, 가장 멋진 순간에 **셔터**를 누른다. 셔터는 카메라를 들여다보는 중에만 눌린다.
4. 제한 시간이 다 지나면 그 순간 **강제 촬영**된다. 폭탄을 쏘지 않았으면 조용한 사진이 찍힌다(폭탄이 사진에 보이면 실패).

#### PHASE 02. ACTION — 셔터 이후 약 10초

셔터 순간의 장면이 그대로 결과 사진이 되고 판정도 이 순간으로만 한다. 이후 연쇄가 계속되는 모습을 약 10초 동안 보여준다.
1. **줌인 불릿캠 (약 2.5초):** 플래시와 함께 시간이 거의 멈추고, 카메라에 달린 줌인 카메라가 렌즈에서 모델의 얼굴까지 날아간다.
2. **모델 주위 카메라 3대 (각 약 2.5초):** 셔터 순간 모델 주위(좌측 낮게, 뒤쪽 높게, 우측 눈높이)에 놓인 카메라 시점으로 차례로 전환, 슬로모션으로 연쇄를 보여준다.
3. 재생이 끝나면 **바로 결과창**으로 넘어간다. 건너뛰기 키로 즉시 넘어갈 수도 있다.

셔터 이후에는 스튜디오를 조작할 수 없다. 폭탄이 터진 뒤 일어난 사고(파괴, 체공, 연쇄)는 셔터 전후 모두 난장판 보너스에 들어간다.

#### PHASE 03. REVIEW — 화보 공개

난장판이 잦아들면 AD가 셔터 순간의 사진을 평가한다.

샷 리스트의 각 항목은 **사진 한 장**으로만 판정한다.

1. **사진에 담겼는가?** 대상이 사진 프레임 안에 있고, 다른 물체에 가려지지 않았는가?
2. **원하는 모습인가?** 모델이 공중에 떠 있는가, 포즈의 정점인가, 얼굴이 카메라를 향하는가, 소품이 지정한 자리에 있는가?

셔터 이후의 난장판은 사진을 바꾸지 않는다. 대신 **난장판 보너스**(부서진 소품, 모델의 체공 시간, 연쇄로 부서지거나 쓰러진 소품)로 점수에 더해진다.

**모든 스테이지 공통 금지 항목: 시한폭탄이 사진에 보이면 안 된다.** 폭탄이 찍히면 그 사진은 실을 수 없다.

결과 화면에는 다음 정보를 표시한다.

- **셔터 순간의 사진** (컬러, 잡지 화보 페이지 레이아웃 — 콘셉트 제목과 함께)
- 샷 리스트 항목별 판정 (찍힘 / 실패, 금지 항목은 깨끗함 / 노출)
- 난장판 보너스 내역
- AD의 한 줄 평
- 최종 점수 및 등급
- 재촬영 또는 다음 촬영

### 4. 카메라 시스템

#### 4-1. 스튜디오 카메라 — 지정된 자리에 고정된 촬영 장비

플레이어가 사용하는 카메라는 평범한 스튜디오 카메라 한 대뿐이며, 스테이지마다 정해진 자리의 삼각대에 고정되어 있다.

주요 기능:
- 스테이지가 정한 위치와 기본 방향에 고정 (플레이어가 옮길 수 없다)
- 플레이어는 SETUP 중 언제든 카메라를 들여다볼 수 있다. 들여다보는 동안에는 걸어 다니거나 물체를 잡을 수 없다
- 들여다보는 동안 정해진 범위 안에서 방향 돌리기(좌우·상하)와 줌. 스테이지에 따라 방향까지 고정된 카메라도 있다
- 뷰파인더: 사진 비율(3:2) 창, 3분할 격자, 포즈 정점 고스트
- **셔터는 시한폭탄 타이머가 끊는다.** 플레이어가 직접 누르는 셔터 버튼은 없다
- 셔터 순간의 프레임이 곧 결과 사진이다

#### 4-2. 멀티앵글 카메라 — ACTION 단계의 연출 시점

멀티앵글 카메라는 플레이어가 조작하는 장비가 아니라, 셔터 이후 자동으로 컷을 나누는 연출용 시점이다. 스테이지마다 배치된 **고정 앵글 카메라 여러 대**(하이앵글, 로우앵글, 측면 등)와 대상을 따라가는 **추적 카메라**를 섞어 쓴다.

| 구간 | 카메라 동작 |
|---|---|
| 셔터 | 셔터 카메라 시점 그대로, 플래시와 함께 거의 정지 |
| 폭발 | 폭탄 클로즈업 → 폭풍이 퍼지는 와이드 |
| 연쇄 | 가장 극적인 대상(모델, 강하게 맞은 소품)을 추적하거나, 그 대상이 잘 보이는 고정 앵글로 컷 |
| 표정 | 모델이 놀라거나 겁에 질리면 얼굴 클로즈업 |
| 마무리 | 사고가 잦아들면 폐허가 된 스튜디오 전체를 보여주는 와이드 샷으로 빠지며 정지 화면 |

- 세트 벽이나 소품을 뚫고 지나가지 않는다.
- 같은 대상에 너무 오래 머물거나 너무 자주 컷하지 않는다.
- 멀미에 민감한 플레이어를 위해 설정에서 카메라 움직임을 줄일 수 있다(줄임 모드는 이동 대신 컷만 사용).

### 5. 스테이지와 AD의 요구

#### 5-1. 스테이지 = 한 편의 화보 촬영

각 스테이지는 **특정 콘셉트의 화보를 찍는 날**이다. 세트, 모델의 의상과 포즈, AD의 요구가 모두 그 화보를 향한다.

- **세트:** 콘셉트에 맞는 스튜디오 (화이트 호리존 스튜디오, 서부극 백롯 등)
- **카메라 자리:** 스튜디오 카메라가 놓이는 위치와 기본 방향, 돌릴 수 있는 범위. 기본 구도 그대로는 화보가 완성되지 않도록 정한다
- **모델:** 콘셉트에 맞는 의상, 허용 포즈 카드 2~3개, 위치 고정 여부
- **시한폭탄:** 카운트다운 시간, 시작 위치(기본 구도 안에 보이게 둔다 — 숨기는 것이 첫 퍼즐), 놓을 수 있는 구역
- **AD의 브리핑:** 어떤 화보인지, 무엇이 보고 싶은지를 AD의 말투로 전달
- **샷 리스트:** 그 사진에 꼭 들어가야 할 요소 3~4개 + 공통 금지 항목(폭탄 노출)

"상자 3개 부수기"처럼 화보와 상관없는 요구는 쓰지 않는다. 모든 요구는 **모델 또는 콘셉트 속 장소·소품**과 묶인다. 예를 들어 꽃잎은 그냥 날리는 것이 아니라 "아라베스크 포즈의 모델 주위로 흩날리는 꽃잎"이다.

#### 5-2. 샷 리스트 항목의 구성

각 항목은 다음 정보를 가진다.

- 항목 ID
- AD의 표현 (예: "공중에서 모자가 머리에서 떠오른 순간을 잡아!")
- 판정 조건: 누가·무엇이(모델 / 소품 분류) / 어떤 모습으로(포즈, 높이, 얼굴 방향, 표정, 구역) / 사진의 어디에(아무 곳 / 중앙 / 3분할 교차점) / 얼마나 보이게(가려지지 않은 비율)
- 필수 / 추가 구분
- 금지 항목 (예: "폭탄이 보이면 안 돼", "모델의 발끝이 잘리면 안 돼")

#### 5-3. 사진 판정 요소 (셔터 순간)

| 요소 | 예 |
|---|---|
| 사진에 담김 | 대상이 프레임 안에 있고 정해진 비율 이상 보임 |
| 체공 | 모델이 바닥에서 일정 높이 이상 떠 있음 |
| 포즈 | 모델이 특정 포즈 카드의 정점 근처 (셔터와의 시간 차) |
| 얼굴 방향 | 모델 얼굴이 카메라를 향함 |
| 표정 | 모델이 특정 표정(시크, 미소, 강렬 등) |
| 구역 | 대상이 특정 구역(창문 프레임, 두 꽃병 사이 등) 안에 있음 |
| 공중의 소품 | 모자·꽃잎·지폐 같은 소품이 공중에 떠 있음 |
| 구도 | 대상이 사진 중앙 또는 3분할 교차점 근처 |
| 잘림 (금지) | 모델의 머리·손·발이 프레임 밖으로 잘림 |
| 노출 (금지) | 시한폭탄이 사진에 보임 |

#### 5-4. 난장판 사건 (셔터 이후, 보너스)

| 사건 | 예 |
|---|---|
| 파괴 | 소품이 부서짐 |
| 넘어뜨림 | 큰 소품이 쓰러짐 |
| 날아감 | 모델이 래그돌로 공중에 뜸 (체공 시간) |
| 분리 | 모자·액세서리가 모델에게서 떨어져 날아감 |

### 7. 모델 (NPC 1명)

모델은 화보의 주인공이자 가장 큰 웃음 포인트다. 모든 스테이지에 **모델은 한 명뿐**이며, 스테이지마다 의상과 헤어가 바뀐다.

**포즈 카드**
- 포즈 카드 하나 = 아크로바틱 동작 하나 (도움닫기 → **정점** → 착지).
- 카드마다 정점까지 걸리는 시간이 있고, 모델은 카운트다운 0에 정점이 오도록 동작을 시작한다.
- 일부 포즈는 보조 장비가 필요하다(트램펄린, 와이어 리그, 받침대). 장비가 모델 근처에 없으면 낮은 기본 버전(제자리 점프 등)으로 대신한다.
- 뷰파인더에 정점 모습이 반투명 고스트로 보인다.

| 포즈 카드 (예) | 장비 | 정점 |
|---|---|---|
| 스플릿 점프 | 트램펄린 | 다리를 일자로 벌린 채 공중 |
| 백플립 | 트램펄린 | 거꾸로 뒤집힌 공중 |
| 핸드스탠드 | 받침대 | 물구나무 정지 |
| 아라베스크 | — | 한 발 서기, 한 다리 뒤로 |
| 와이어 스윙 | 와이어 리그 | 공중에서 몸을 뻗은 스윙 |
| 모자 토스 점프 | — | 점프 정점에서 모자가 머리 위로 |

**물리 반응 (셔터 이후)**
- 폭풍이나 날아온 물체에 맞으면 충격의 크기에 따라 반응한다.
  - 약한 충격: 휘청이며 버틴다(몸 일부만 물리 반응).
  - 강한 충격: 포즈 그대로 래그돌이 되어 날아간다.
- 날아간 모델은 다른 소품과 부딪치며 2차 사고를 만든다.
- 모자·액세서리 같은 착용 소품은 충격에 떨어져 따로 날아갈 수 있다.

**표정**
- 모델은 상황에 따라 표정이 바뀐다. 슬로모션 덕분에 표정 변화가 또렷하게 보인다.

| 상황 | 표정 |
|---|---|
| 촬영 대기 | 포즈 카드의 화보 표정 (시크, 미소, 강렬, 윙크 등) |
| 마지막 카운트다운 | 집중 |
| 셔터 순간 (포즈 정점) | 화보 표정 최대 |
| 폭풍이 다가옴 | 놀람 (눈 크게, 입 벌림) |
| 맞음 / 날아가는 중 | 겁에 질림 · 비명 |
| 착지 · 충돌 | 아픔 |
| 사고 후 | 어리둥절 → 잠시 뒤 다시 화보 표정 (프로 근성) |

### 8. 실패 및 재촬영 시스템

재촬영은 SETUP 단계부터 다시 시작한다. 카운트다운도 처음부터 다시 흐른다.

재촬영 시에는 스튜디오의 상태를 복원하는 기능을 제공한다.

- 이동된 소품·장비 복원
- 파괴된 오브젝트 복원
- 시한폭탄 복원 (다시 놓을 수 있는 상태)
- 모델 위치·자세·표정 복원 (선택한 포즈 카드는 유지)
- 사진과 사고 기록 초기화

플레이어가 매번 모든 준비를 처음부터 해야 하는 피로를 줄이기 위해, 이전 촬영 준비 상태를 저장하고 다시 불러오는 기능도 고려한다.

### 9. 메뉴, HUD, 설정

#### 9-1. HUD 원칙
- **HUD에 조작 키 설명을 표시하지 않는다.** 화면은 사진을 찍는 공간이다.
- SETUP 중 HUD: 시한폭탄 카운트다운(마지막 10초 붉게), AD의 브리핑과 샷 리스트, 카메라를 들여다볼 때 뷰파인더(3:2 창, 3분할 격자, 포즈 고스트).
- ACTION 중 HUD: 슬로모션 표시와 현재 앵글 이름(예: "CAM 2 · LOW") 정도만.
- 잡을 수 있는 물체는 키 문구 대신 외곽선 강조로 알려준다.

#### 9-2. Tab 메뉴 — 스튜디오 촬영 매뉴얼
Tab 키를 누르면 언제든 게임이 일시정지되고(카운트다운도 멈춤) **스튜디오 촬영 매뉴얼**(스프링 제본 콘티북) 모양의 메뉴가 열린다. Esc로도 열고 닫을 수 있다.

| 탭 | 내용 |
|---|---|
| 설명서 | 조작법 안내. 현재 키 설정을 그대로 보여준다 |
| 키 설정 | 키보드·마우스·게임패드 키 변경, 중복 키 경고, 기본값 복원 |
| 오디오 | 전체·음악·효과음·UI·환경음 볼륨, 창이 비활성일 때 음소거 |
| 그래픽 | 화면 모드, 해상도, 수직동기화, 프레임 제한, 품질 프리셋과 세부 항목, 해상도 배율, 밝기, 시야각 |
| 효과 | 화면 흔들림 강도, 셔터 플래시, 렌즈 효과(비네팅·색수차) 강도, 모션 블러, 슬로모션 피사계 심도, 멀티앵글 카메라 움직임(기본/줄임) |

설정은 저장되어 다음 실행에도 유지된다.

**데이터 기록**

셔터 순간에는 **사진 스냅샷**을 한 번 기록한다. 대상(모델, 착용 소품, 소품, 폭탄)마다 다음 정보를 담는다.

- 대상 ID, 분류, 착용 소품이면 주인
- 사진 프레임 안 여부, 가려지지 않은 비율, 화면 위치·크기
- 바닥에서의 높이, 공중 여부
- 모델이면 포즈 카드와 정점과의 시간 차, 얼굴 방향, 표정, 잘린 신체 부위
- 들어 있는 구역

셔터 이후에는 **사고 이벤트**를 기록한다.

- 사건 종류
- 대상 액터
- 발생 위치와 구역
- 발생 시간
- 충돌 강도

리플레이가 없으므로 물체의 움직임 전체를 녹화하지 않는다. 사고 기록은 난장판 보너스와 멀티앵글 대상 선정에만 쓴다.

### 11. MVP 개발 범위

**1단계 — 핵심 플레이 루프**
- 플레이어가 소품, 모델, 시한폭탄을 옮길 수 있다.
- 시한폭탄 카운트다운이 SETUP 제한 시간으로 흐르고, 리모컨으로 마지막 3초로 당길 수 있다.
- 지정된 자리에 고정된 카메라를 들여다보고 구도를 잡을 수 있다.
- 카운트다운 0에 자동 셔터로 사진이 찍히고, 직후 폭탄이 터지며 세계가 0.2배속으로 느려진다.
- 폭풍에 소품이 부서지고 모델이 날아간다.

**2단계 — 모델과 멀티앵글**
- 포즈 카드, 카운트다운 동기, 포즈 고스트
- 모델 물리 반응(휘청임, 래그돌), 착용 소품 분리
- 상황별 표정 변화
- 폭탄 클로즈업 → 추적·고정 앵글 컷 → 와이드 마무리 멀티앵글

**3단계 — 스테이지와 평가**
- 화보 콘셉트와 샷 리스트 데이터
- 사진 스냅샷 판정 (폭탄 노출 금지 포함), 난장판 보너스
- 결과 화면 (화보 레이아웃의 사진)

**4단계 — 메뉴와 연출 마감**
- Tab 메뉴 (설명서, 키·오디오·그래픽·효과 설정)
- 음악, 셔터 플래시, 렌즈 효과

**5단계 — 콘텐츠 확장**
- 새 트리거 장치
- 새 세트와 스테이지
- 다양한 포즈 카드와 의상

### 12. 게임의 핵심 정체성

《Super Camera Demolition》은 사고를 일으키는 것만으로 끝나는 게임이 아니다.

플레이어는 째깍거리는 시한폭탄 앞에서 단 한 대의 카메라로 모델의 가장 아름다운 순간을 설계한다. 셔터가 찰칵하는 순간 그 장면은 영원한 화보가 되고, 바로 다음 순간 스튜디오는 0.2배속의 멀티앵글 속에서 산산조각 난다.

**플레이어는 완벽한 한 장을 설계하는 포토그래퍼이자, 그 직후의 대참사를 설계하는 연출자다.**

게임의 핵심 경험은 다음 한 문장으로 요약된다.

**"폭발 직전의 1초를, 세상에서 가장 완벽한 화보로 만들어라."**
