# Super Camera Demolition — UI 디자인 가이드

**Version:** 0.1 · **Updated:** 2026-11-14
**근거 문서:** [기획서](01_게임기획서.md)
**적용 범위:** HUD, 뷰파인더, ACTION 자막, 결과 화면(화보 페이지), Tab 메뉴(촬영 매뉴얼), 타임키퍼 전광판, 폰트, 모션 그래픽

> 기획서끼리 서로 다를 때는 **v0.6 변경점이 우선**한다. 예: §9-1의 "HUD 카운트다운"은 v0.6에서 삭제되었고, 남은 시간은 **타임키퍼 전광판**(월드 안 UI)만 보여준다.

## 0. 한 줄 콘셉트

**"패션 잡지 「BOOM」의 편집 디자인 + 포토그래퍼의 뷰파인더 + 만화 같은 폭발."**

| 축 | 느낌 | 어디에 쓰나 |
|---|---|---|
| **Editorial (잡지)** | 굵은 세리프 마스트헤드, 넓은 여백, 흑백 + 강조색 하나 | 결과 화면, 스테이지 타이틀, AD 브리핑 |
| **Viewfinder (카메라)** | 얇은 흰 선, 모노스페이스 숫자, 촬영 데이터 표기 | 뷰파인더, ACTION 자막, 조준선 |
| **Cartoon BOOM (폭발)** | 기울어진 스탬프, 빨강·노랑, 짧고 큰 튐 | 셔터 "CLICK!", 등급 도장, 폭탄 노출 경고 |
| **Analog Craft (콘티북)** | 스프링 제본, 모눈종이, 마스킹테이프, 손글씨 메모 | Tab 메뉴 |

코미디의 핵심은 **"완벽한 화보 vs 폐허 스튜디오"의 대비**다. UI도 같은 대비를 쓴다. 평소 UI는 차분하고 고급스러운 잡지처럼, 폭발·실패 순간만 만화처럼 튄다. 튀는 요소가 늘 보이면 대비가 약해지므로 **카툰 스타일은 이벤트 순간에만** 쓴다.

## 1. 설계 원칙

1. **화면은 사진을 찍는 공간이다.** HUD에 조작 키·키 힌트를 절대 표시하지 않는다(기획서 §9-1, 지시서 §3.10). 상호작용은 외곽선 강조 + ID 이름표로만 알린다.
2. **시간은 월드 안에서 보여준다.** 남은 시간은 타임키퍼 전광판(디에제틱 UI)으로만 보여준다. HUD 시계는 없다.
3. **단계마다 HUD 밀도가 다르다.** SETUP은 최소한만, 뷰파인더는 촬영 정보만, ACTION은 자막 한 줄, REVIEW는 잡지 페이지 전체를 쓴다.
4. **UI 시간은 실제 시간이다.** 세상이 0.25배(총), 0.02배(불릿캠)로 느려져도 UI 애니메이션은 정상 속도로 재생한다(지시서 §3.2.4). UMG 위젯 애니메이션은 기본적으로 실제 시간이므로, 머티리얼 애니메이션도 `Time`이 아니라 위젯이 넘겨주는 실제 시간 파라미터를 쓴다.
5. **색으로만 알리지 않는다.** 판정 결과(In the Shot / Missed / Clean / Bomb in Shot! / Cropped)는 항상 **아이콘 + 글자 + 색** 세 가지로 표시한다.
6. **컨트롤러 먼저.** 메뉴·결과 화면·포즈 카드 패널은 마우스 없이 끝까지 조작할 수 있어야 한다. 지금은 게임패드 바인딩이 없지만(DevNotes) 포커스 구조는 미리 만들어 둔다.
7. **모든 문구는 String Table에서 온다.** 영어가 기본이고, 폰트는 한글 서브폰트를 추가할 수 있는 컴포짓 폰트로 만든다(지시서 §3.10).

## 2. 디자인 토큰

### 2-1. 색

| 토큰 | HEX | 용도 |
|---|---|---|
| `Ink` | `#141414` | 기본 텍스트(밝은 배경), 결과 페이지 본문 |
| `Paper` | `#F6F2EA` | 결과 페이지·매뉴얼 종이 (순백보다 따뜻한 아이보리) |
| `Flash` | `#FFFFFF` | 셔터 플래시, 뷰파인더 선 |
| `BoomRed` | `#E8322B` | **유일한 브랜드 강조색.** 「BOOM」 로고, 폭탄 경고, 마지막 10초, 실패 |
| `Caution` | `#FFC93C` | 폭탄 관련 주의(조준 중 폭탄 이름표, 슬로모션 표시), 마스킹테이프 |
| `Pass` | `#2BB3A3` | 성공 판정 (빨강과 구분되도록 초록이 아닌 청록) |
| `Smoke` | `#141414` @ 55% | HUD 카드 배경(반투명), 뷰파인더 3:2 바깥 어둡게 |

| `Grid` | `#BFD7EA` | 매뉴얼 모눈선 |

**스튜디오별 액센트** (스테이지 타이틀·결과 페이지 테두리에만 쓴다. HUD에는 쓰지 않는다)

| 세트 | 액센트 | 모티프 |
|---|---|---|
| SET-01 Studio A (화이트 호리존) | `#141414` 모노크롬 | 기본 잡지 |
| SET-02/03 Western | `#C8752E` 석양 오렌지 | 현상수배 포스터 테두리 |
| SET-04 Sci-Fi | `#3DE0FF` 시안 | 그린스크린 마커 십자 |
| SET-05 Romance | `#F29BB5` 파스텔 핑크 | 리본 모서리 |

대비 규칙: 본문 텍스트는 배경 대비 **4.5:1 이상**, HUD 텍스트는 반투명 카드 위에서 **7:1 이상**이 되게 한다. `BoomRed` 위에는 흰 글자만 쓴다.

### 2-2. 간격·크기 (1080p 기준, 해상도에 비례해 스케일)

- 간격 단위 `8px`: 4 / 8 / 16 / 24 / 32 / 48
- 모서리: HUD 카드 `4px`, 버튼 `2px`(잡지 느낌은 각진 모서리), 스탬프·태그만 둥글게
- 외곽선 두께: 뷰파인더 선 `1.5px`, 포커스 테두리 `3px`
- **세이프 존:** 모든 HUD 요소는 화면 가장자리에서 **5% 안쪽(title safe 90%)** 에 둔다. 설정에 세이프 존 슬라이더(90~100%)를 둔다.
- UE: `DPI Scaling` 커브를 짧은 변 1080 = 1.0 기준으로 설정. 고정 픽셀 위치 대신 앵커 + 패딩을 쓴다.

## 3. 폰트

### 3-1. 폰트 패밀리 (전부 SIL OFL 1.1 — 상용 게임에 무료로 포함 가능)

| 역할 | 폰트 | 이유 | 쓰는 곳 |
|---|---|---|---|
| **Display (잡지 마스트헤드)** | **Bodoni Moda** (Bold / Black, Italic) | 굵기 대비가 큰 디도네 세리프 = 패션 잡지의 상징 | 「BOOM」 로고, 스테이지 제목, 결과 페이지 제목, 등급 문자 |
| **UI Sans (본문)** | **Archivo** (Medium / SemiBold / ExtraBold, Condensed 폭 포함) | 그로테스크 산세리프, x-height가 높아 작은 크기에서도 잘 읽히고, Condensed 폭으로 좁은 HUD에 맞음 | HUD, 샷 리스트, 버튼, 메뉴 |
| **Mono (카메라 데이터)** | **JetBrains Mono** (Medium / Bold) | 숫자 폭이 고정되어 카운트업·FOV 숫자가 흔들리지 않음 | 뷰파인더 데이터, ACTION 자막, 점수 카운트업 |
| **Handwritten (콘티 메모)** | **Caveat** (Bold) | 포토그래퍼·AD의 손글씨 메모 느낌 | 매뉴얼 여백 메모, AD 한 줄 평 서명 |
| **LED (전광판)** | **DSEG7 Classic** (Bold) | 7세그먼트 숫자 | 타임키퍼 전광판 숫자 |
| **한글 서브폰트 (향후)** | **Pretendard** (Medium / Bold) | 무료 OFL, Archivo와 획 굵기·비례가 비슷함 | 컴포짓 폰트의 한글 범위 |

Light / Thin 굵기는 쓰지 않는다(작은 크기·움직이는 배경에서 사라짐). 손글씨 폰트(Caveat)는 **장식용 메모에만** 쓰고, 설정 항목·판정 결과 같은 정보에는 쓰지 않는다.

### 3-2. UE 폰트 에셋

| 에셋 | 구성 |
|---|---|
| `F_SCD_UI` (Composite) | 기본: Archivo · 서브폰트(Hangul 범위): Pretendard — 지시서 §3.10 |
| `F_SCD_Display` (Composite) | 기본: Bodoni Moda · 서브폰트(Hangul): Pretendard Bold (한글 세리프 대안: 나눔명조 ExtraBold) |
| `F_SCD_Mono` | JetBrains Mono |
| `F_SCD_Hand` | Caveat |
| `F_SCD_LED` | DSEG7 Classic — 타임키퍼 `UTextRenderComponent`는 오프라인 폰트(`Font Cache Type: Offline`)로 따로 임포트 |

- 위치: `Content/SCD/UI/Fonts/`, 라이선스 텍스트(OFL.txt)를 같은 폴더에 둔다.
- 기본 하이팅(hinting): Auto, 한글 서브폰트는 `Light` 하이팅 → 작은 크기 번짐 방지.

### 3-3. 타입 스케일 (1080p 기준)

| 토큰 | 폰트 / 굵기 | 크기 | 자간 | 예 |

## 4. 화면별 설계

### 4-1. SETUP HUD (1인칭으로 돌아다니는 중)

```
┌──────────────────────────────────────────────────────────────┐
│ ┌ BRIEF ───────────────┐                                     │
│ │ ST-01 · STUDIO A     │                                     │
│ │ Take Off             │                 [Balloon]           │ ← 월드 이름표
│ │ ─────────────────    │                    ◎                │
│ │ ■ Airborne 50cm+     │                    ·                │ ← 조준선
│ │ ■ Eyes on the lens   │                                     │
│ │ □ Balloons in frame  │                                     │
│ │ ⊘ No bomb in shot    │                                     │
│ └──────────────────────┘                                     │
│                                                              │
│                                      (타임키퍼가 뛰어다님)   │
└──────────────────────────────────────────────────────────────┘
```

| 요소 | 디자인 | 동작 |
|---|---|---|
| **조준선** | 지름 6px 흰 점 + `Ink` 1px 테두리. 상호작용 대상 위에서는 지름 20px 원(1.5px)으로 열림 | 열림·닫힘 120ms ease-out |
| **ID 이름표** (월드 공간) | 대상 위쪽 고정 위치, `Caption` 폰트, 흰 글자 + `Smoke` 카드, 아래 작은 꼬리(▼). **폭탄**은 `Caution` 노랑 카드 + 검은 글자, 모델은 이름 앞에 ★ | 대상 조준 시 페이드인 150ms + 4px 위로 이동, 해제 시 페이드아웃 250ms |
| **외곽선 강조** | 포스트프로세스 외곽선 2px, 흰색. 폭탄은 `Caution`. 잡고 있는 물체는 외곽선 점선 | 대상이 바뀔 때 즉시 |
| **브리핑 카드** (좌상단) | `Smoke` 카드 폭 360px. 스테이지 ID(`Caption`), 제목(`H1`을 36px로), 샷 리스트. 필수 ■, 추가 □, 금지 ⊘ 아이콘 | 스테이지 시작 시 펼쳐짐 → **8초 뒤 제목 한 줄로 접힘**. 뷰파인더를 들여다보면 다시 펼쳐짐 |
| **포즈 카드 패널** (모델에게 말 걸 때) | 화면 아래 중앙에 폴라로이드 모양 카드 2~3장. 카드에 포즈 실루엣 + 이름 + 필요 장비 아이콘(트램펄린/와이어/받침대). 장비가 멀면 카드 모서리에 `Caution` "FALLBACK" 태그. 위쪽에 모델 대사 말풍선 | 아래에서 24px 올라오며 페이드인, 카드는 40ms 간격으로 순서대로 등장. 선택 카드는 -3° 회전 + 1.06배 |

**키 힌트를 쓰지 않는 대신** 브리핑 카드 아래에 "Tab: Manual" 같은 문구도 넣지 않는다. 처음 플레이 안내는 ST-01(튜토리얼)의 **AD 대사**와 매뉴얼로만 한다.

### 4-2. 타임키퍼 전광판 (디에제틱 UI)

타임키퍼가 들고 있는 LED 보드가 이 게임의 유일한 시계다. 사진에는 찍히지 않는다(지시서 v0.6).

| 상태 | 표시 |
|---|---|
| 평소 | 검은 판 위 `DSEG7` 숫자, 앰버 `#FFB23F`, 꺼진 세그먼트는 8% 밝기로 비침 (`1:24`) |
| 마지막 10초 | 숫자가 `BoomRed`로 바뀌고 소수 1자리 표시(`9.4`), 정수 초마다 0.12초 동안 1.15배로 커졌다 돌아옴. 테두리 LED가 같이 깜빡임 |
| 마지막 3초 | 위 + 타임키퍼가 뛰면서 보드를 머리 위로 흔듦(애니메이션), 째깍 음이 높아짐(지시서 S-10) |
| 0 / 강제 촬영 | 보드에 "SNAP" 표시 후 ACTION에서 숨김 |
| 일시정지 | 숫자 깜빡임 정지 |

- 가독성: 보드 숫자 높이는 플레이어 거리(`TimekeeperRadius`)에서 **화면 높이의 3% 이상**이 되게 크기를 정한다. 보드는 자체 발광(Emissive) 머티리얼로 그늘에서도 보이게 한다.
- 색만으로 알리지 않는다: 마지막 10초는 색 + 소수점 표시 + 깜빡임 세 가지로 알린다.
- **접근성 대체:** 설정 > 효과에 "Screen-edge timer"(기본 끔)를 둔다. 켜면 마지막 10초에만 화면 상단 중앙에 작은 `Data` 숫자를 띄운다. 타임키퍼가 시야 밖에 있을 때를 위한 대비책이다.

### 4-3. 총 조준 & 슬로모션

| 요소 | 디자인 |
|---|---|
| **조준 줌 (RMB)** | 조준선이 사라지고 가는 십자(길이 24px, 가운데 6px 비움)로 바뀜. 화면 가장자리 비네팅 20% | 
| **첫 발 = 슬로모션 시작** | 화면 좌상단 브리핑 카드 아래에 `Caution` 태그 **"SLOW-MO 0.25×"**(`Data` 폰트). 화면 가장자리에 1px 노란 프레임이 0.3초 페이드인 |
| **폭탄 명중** | 총알이 맞는 순간 화면 중앙에 짧은 "BOOM!" 스탬프(§5-3). 이후 연쇄는 월드에서 보여주므로 HUD는 조용히 |

### 4-4. 뷰파인더 (카메라를 들여다보는 중)

```
┌──────────────────────────────────────────────────────────────┐
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
```

뷰파인더 진입·이탈: 검은 아이리스가 닫혔다 열리는 연출(총 220ms, §5-2). Reduce Motion이 켜져 있으면 120ms 크로스페이드.

|---|---|

| **레터박스** | 위아래 검은 띠(화면 높이의 각 8%), 영화적 연출 |
| **앵글 자막** | 좌하단(레터박스 안) `Data` 폰트: `ZOOM-IN CAM · 0.02×` → `CAM 1 · LOW LEFT` / `CAM 2 · HIGH BACK` / `CAM 3 · EYE RIGHT`. 앞에 빨간 ● |
| **타임코드** | 우하단 `00:02:14` 형식 타임코드(실제 시간 진행) — 방송 촬영 느낌 |
| **건너뛰기 진행** | 건너뛰기 키를 누르면 우하단 타임코드 옆에 작은 원형 진행 표시 (키 이름 없음) |

### 4-6. REVIEW — 결과 화면 (화보 페이지)

잡지 「BOOM」의 펼침면 한 장이 이 게임의 보상이다. 가장 공을 들이는 화면이다.

```
┌──────────────────────────────────────────────────────────────┐
│  BOOM                         ISSUE 01 · STUDIO A · NOV 2026 │ ← 마스트헤드
│ ┌───────────────────────────────────┐  SHOT LIST             │
│ │                                   │  ✔ Airborne 50cm+  IN  │
│ │                                   │  ✔ Eyes on the lens IN │
│ │        [셔터 순간의 사진 3:2]       │  ✖ Balloons     MISSED │
│ │                                   │  ✔ No bomb       CLEAN │
│ │                                   │                        │
│ └───────────────────────────────────┘  PHOTO BONUS   +300    │
│  Take Off                              STUDIO CHAOS  +180    │
│  "Gravity? Never heard of her." — AD   ─────────────────     │
│                                        SCORE   1,240   ┌──┐  │
│  [ RESHOOT ]   [ NEXT SHOOT ▶ ]                        │A │  │ ← 등급 도장
│                                                        └──┘  │
└──────────────────────────────────────────────────────────────┘
```

- **배경:** `Paper` 아이보리 + 아주 옅은 종이 질감. 사진은 흰 테두리 없이 꽉 차게, 그림자 0.
- **마스트헤드:** `Masthead` 「BOOM」, 오른쪽에 발행 정보(`Caption`).
- **사진 아래:** 콘셉트 제목 `H1`(Bodoni Italic), AD 한 줄 평은 `Hand` 폰트 + "— AD" 서명.
- **샷 리스트:** 결과 상태 = 아이콘 + 글자 + 색.

| 상태 (`ST_UI` 키) | 아이콘 | 글자 | 색 |
|---|---|---|---|
| `SHOT_CAPTURED` | ✔ | In the Shot | `Pass` |
| `SHOT_MISSED` | ✖ | Missed | `Graphite` (추가 항목) / `BoomRed` (필수 항목) |
| `SHOT_CLEAN` | ⊘ → ✔ | Clean | `Pass` |
| `SHOT_EXPOSED` | 💣 아이콘 | Bomb in Shot! | `BoomRed` + 사진 위에 "REJECTED" 빨간 스탬프 |
| `SHOT_CROPPED` | ✂ | Cropped | `BoomRed` |

- **난장판 보너스:** 항목별로 한 줄씩(부서진 소품, 체공 시간, 연쇄 사고), 숫자는 `Data`, 오른쪽 정렬.
- **등급 도장:** 지름 120px 원형 도장, `Display` 폰트 글자, `BoomRed` 잉크 질감, -8° 기울기.
- **버튼:** 각진 직사각형. 기본 상태는 `Ink` 테두리 2px + 투명 배경, 포커스는 `Ink` 배경 + `Paper` 글자 + 왼쪽 4px `BoomRed` 막대. 필수 항목 실패로 잠긴 *Next Shoot*은 `Graphite` + 🔒 아이콘 + 툴팁 문구(`ST_UI`).
- **기본 포커스:** 성공하면 *Next Shoot*, 실패하면 *Reshoot*.
- **스튜디오 액센트:** 페이지 테두리 장식만 바꾼다(서부극 = 현상수배 포스터 톱니 테두리, SF = 그린스크린 마커 십자, 로맨스 = 리본 모서리).

### 4-7. Tab 메뉴 — 스튜디오 촬영 매뉴얼 (콘티북)

- **모양:** 화면 중앙 80% 크기의 펼친 스프링 제본 콘티북. 왼쪽 페이지 = 탭 목차, 오른쪽 페이지 = 내용. 배경은 게임 화면을 흐리게(가우시안 블러 + `Smoke` 50%).
- **탭:** 책 위쪽에 꽂힌 색인 탭 5개(Manual, Controls, Audio, Graphics, Effects). 선택된 탭은 8px 더 위로 올라오고 `Paper` 색, 나머지는 한 단계 어두운 색.
- **종이:** `Paper` + `Grid` 모눈선(24px 간격, 25% 불투명). 제목은 `H2`, 항목은 `Body`, 여백 메모(예: "↑ turn this down if you get motion sick")는 `Hand` 폰트 + 연필 회색.
- **슬라이더:** 가는 `Ink` 선 + 마스킹테이프 모양 손잡이(`Caution`). 숫자 값은 오른쪽 `Data`.
- **토글:** 체크박스를 손그림 □ / ☑ 모양으로.
- **Manual 탭:** 현재 바인딩을 읽어 **키캡 그림**으로 보여준다(키 이름은 엔진 표시 이름). 이 화면만 키 이름이 나올 수 있는 곳이다.
- **Controls 탭:** 키 변경 대기 중에는 해당 줄에 `Caution` 마스킹테이프가 깔리고 "Press a key…" 표시(`ST_Menu`). 중복 키는 두 줄 모두 `BoomRed` 밑줄 + ⚠ 아이콘.
- **하단 바:** Apply / Revert / Defaults 버튼 + 오른쪽 끝에 Reset scene(빨간 테두리, 확인 팝업).
- **컨트롤러:** LB/RB = 탭 전환, D-pad = 항목 이동(마지막 항목에서 첫 항목으로 돌아옴), A = 선택, B = 뒤로/닫기. 메뉴를 다시 열면 마지막 탭·항목으로 돌아온다.

### 4-8. 스테이지 시작 타이틀 & 세트 배너

- 스테이지 시작: 화면 중앙에 잡지 표지처럼 `Caption` "ST-01 · STUDIO A" → `H1` 제목 *Take Off* → AD 브리핑 대사가 `Body`로 아래에. 2.5초 유지 후 제목이 좌상단 브리핑 카드 자리로 줄어들며 이동(§5-2).
- 새 세트 진입(DevNotes "a new set shows a banner"): 세트 이름을 스튜디오 액센트 색 띠 위에 `Masthead` 크기로 1.5초.
- 이 타이틀이 떠 있는 동안에도 카운트다운은 흐르므로 **3초를 넘기지 않는다**(아무 키나 누르면 바로 접힘).

## 5. 모션 그래픽

### 5-1. 공통 규칙

| 규칙 | 값 |
|---|---|
| 시간 기준 | **실제 시간.** 월드 시간 배율(0.25 / 0.02)과 일시정지에 영향받지 않음 |
| 기본 길이 | 정보 UI 등장 150ms, 퇴장 250ms, 화면 전환 220~400ms |
| 상한 | 정보 UI는 **200ms 이하**(스킬 기준). 그보다 긴 것은 결과 화면 연출·셔터처럼 "보는 연출"만 |
| 기본 이징 | 등장 `ease-out cubic`, 퇴장 `ease-in quad`. 카툰 스탬프만 `back-out`(살짝 튀어나왔다 돌아옴, overshoot 1.4) |
| 이동 거리 | 정보 UI는 4~24px. 화면 밖에서 미끄러져 들어오는 연출 금지 |
| UI 흔들림 금지 | 카메라 흔들림은 월드에만. HUD는 흔들지 않는다(가독성·멀미) |
| 동시 재생 | 한 화면에서 동시에 움직이는 요소는 최대 3개 |

### 5-2. 이징 프리셋 (UMG 커브 에셋 `Curve_SCD_*`)

| 이름 | 커브 | 쓰임 |
|---|---|---|
| `Snap` | cubic-bezier(0.2, 0.9, 0.3, 1.0) | 조준선, 이름표, 버튼 포커스 |
| `Settle` | cubic-bezier(0.25, 1.0, 0.5, 1.0) | 카드·패널 등장, 타이틀 이동 |
| `Stamp` | back-out, overshoot 1.4 | CLICK!, BOOM!, 등급 도장, REJECTED |
| `Develop` | ease-in-out sine | 사진 현상(색이 차오름) |
| `Count` | ease-out expo | 점수 카운트업 |

### 5-3. 시그니처 시퀀스

**① 셔터 "CLICK!" (셔터 → ACTION 진입, 총 약 0.6초, 실제 시간)**

| 시간 | 일 |
|---|---|
| 0ms | 뷰파인더 3:2 창이 위아래에서 검은 셔터 막이 닫힘(60ms) |
| 60ms | 흰색 풀스크린 플래시 100% (설정 `셔터 플래시` 꺼짐 → 30% 회색 플래시로 대체) |
| 60–360ms | 플래시가 `ease-out`으로 사라짐. 동시에 화면 중앙에 **"CLICK!"** 스탬프(`Stamp` 96px, `Ink`, -6°): 0.6배 → 1.1배 → 1.0배, 160ms |
| 360ms | 스탬프가 페이드아웃(200ms), 레터박스 띠가 위아래에서 들어옴(200ms), 앵글 자막 등장 |

**② "BOOM!" (총알이 폭탄 명중, SETUP 중)**

- 폭탄 위치를 화면에 투영한 자리에 만화 폭발 말풍선 모양(톱니 테두리) + "BOOM!" `Stamp` 72px, `BoomRed` 바탕 + 흰 글자 + `Caution` 외곽선.
- 0 → 1.15 → 1.0배 (180ms, `Stamp`) → 400ms 유지 → 150ms 페이드아웃. 전체 약 0.7초(실제 시간).
- 동시에 좌상단 "SLOW-MO" 태그가 깜빡 1회. 화면 흔들림은 월드 카메라에만(Juice).

**③ 결과 화면 공개 (REVIEW 진입, 총 약 3초, 아무 입력이나 누르면 즉시 최종 상태로)**

| 시간 | 일 |
|---|---|
| 0ms | 마지막 ACTION 화면이 흰색으로 페이드(250ms) |
| 250ms | 마스트헤드 「BOOM」이 위에서 12px 내려오며 페이드인(200ms, `Settle`) |
| 400ms | **사진 현상:** 사진이 회색 반투명(채도 0, 밝기 1.4)에서 원래 색으로 600ms 동안 차오름(`Develop`) — 즉석 사진이 현상되는 느낌. 머티리얼 파라미터 `Develop`(0→1) |
| 1000ms | 제목·AD 한 줄 평 페이드인(150ms). AD 평은 글씨가 왼쪽에서 오른쪽으로 마스크로 써지는 효과(400ms) |
| 1200ms | 샷 리스트 항목이 한 줄씩 120ms 간격으로 등장, 각 항목 아이콘이 `Stamp`로 찍힘 + 짧은 효과음 |
| — | 폭탄 노출이면 이 시점에 사진 위로 "REJECTED" 빨간 스탬프(`Stamp`, -12°) |
| 1900ms | 보너스 줄 등장, 숫자는 0에서 카운트업(500ms, `Count`) |
| 2400ms | 최종 점수 카운트업(500ms) 후 **등급 도장**이 1.6배에서 1.0배로 쾅(140ms, `Stamp`) + 잉크 번짐 텍스처 |
| 2900ms | 버튼 페이드인, 기본 버튼에 포커스 |

**④ 브리핑 카드 접힘**

- 스테이지 타이틀 → 좌상단 카드: 위치·크기 보간 400ms `Settle`. Reduce Motion이면 타이틀 페이드아웃 + 카드 페이드인(150ms).

**⑤ 마지막 10초 (전광판)**

- 정수 초마다 숫자 펄스(1.0 → 1.15 → 1.0, 120ms). HUD에는 아무것도 추가하지 않는다(키 힌트·경고 문구 없음). 긴장은 전광판, 째깍 음, 음악으로 만든다.

### 5-4. Reduce Motion (설정 > 효과)

| 항목 | 기본 | Reduce Motion 켬 |
|---|---|---|
| 뷰파인더 아이리스 | 220ms 닫힘·열림 | 120ms 크로스페이드 |
| 스탬프(CLICK!/BOOM!/등급) | 크기 튐 | 크기 고정, 100ms 페이드인 |
| 타이틀 → 카드 이동 | 위치 보간 | 페이드만 |
| 사진 현상 | 600ms | 200ms |
| 전광판 펄스 | 크기 펄스 | 색 변화만 |
| 셔터 플래시 | 흰색 100% | 별도 설정(셔터 플래시 끔 = 30% 회색) |

기존 설정 "멀티앵글 카메라 움직임 Full/Reduced"(기획서 §9-2)와는 별개 항목이다. 둘 다 효과 탭에 두고, 매뉴얼 여백 메모로 함께 쓰라고 안내한다.

## 8. 작업 순서 제안

1. 폰트 임포트 + `F_SCD_*` 컴포짓 폰트 + `DA_SCD_UIStyle` 토큰 (모든 화면의 바탕)
2. 결과 화면 (보상 화면이자 게임의 얼굴 — 효과가 가장 큼)
3. 뷰파인더 + 셔터 "CLICK!" 시퀀스 (핵심 루프의 손맛)
4. SETUP HUD (이름표, 브리핑 카드, 포즈 카드) + 타임키퍼 전광판 머티리얼
5. Tab 매뉴얼 (CommonUI, 컨트롤러 탐색)
6. 접근성 설정 4개 (Reduce Motion, 텍스트 크기, 세이프 존, Screen-edge timer)

각 단계 뒤에 1080p / 1440p / 4K 스크린샷과 TV 거리 가독성(3m)을 확인한다.
